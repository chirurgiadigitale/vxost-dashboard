Change the MySQL Temporary Files Directory

By default, MySQL’s temporary files are stored in the xamppfiles\temp\mysql subdirectory of your XAMPP installation directory (usually, /Applications/XAMPP). In case you wish to change the location of this directory, follow these steps:

  1. Edit the my.cnf file in the xamppfiles/etc/ subdirectory of your XAMPP installation directory. Within this file, find the tmpdir variable in the [mysqld] section and change it to reflect your new desired location. For example:

    tmpdir = "/tmp"

  2. Save your changes to the file.

  3. Restart the MySQL server using the XAMPP control panel.

MySQL’s temporary files should now get created in the new location.
