Solo per lo sviluppo

VXOST non è inteso per la produzione ma solo per ambienti di sviluppo: la configurazione è volutamente aperta per agevolare il lavoro in locale, ma risulta insicura se l'installazione viene resa accessibile ad altri.

Sta arrivando un gateway. VXOST GATEWAY, in breve VXOST WAY, renderà questi progetti raggiungibili da fuori questo Mac. Un'installazione già chiusa è pronta così com'è: la macchina virtuale e il client si collegano senza altro lavoro. Conviene configurarla bene fin dall'inizio, invece di disfare più avanti le impostazioni aperte.

Esegui sudo /Applications/VXOST/vxostfiles/vxost security per mettere in sicurezza l'installazione.

Cos'è VXOST

Una distribuzione Apache gratuita che installa un server web completo sul tuo computer: Apache, il database MariaDB, PHP e Perl, pronti per sviluppare e collaudare in locale senza toccare un server di produzione.
