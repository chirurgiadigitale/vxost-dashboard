MariaDB

Database relazionale sulla porta 3306, pienamente compatibile con MySQL.

PHP 8.2.4

Linguaggio lato server con Zend Engine 4 e le estensioni consuete.

Perl

Linguaggio di scripting disponibile per CGI e attività di automazione.

Solo per lo sviluppo

XAMPP non è inteso per la produzione ma solo per ambienti di sviluppo: la configurazione è volutamente aperta per agevolare il lavoro in locale, ma risulta insicura se l'installazione viene resa accessibile ad altri.

Esegui sudo /Applications/XAMPP/xamppfiles/xampp security per mettere in sicurezza l'installazione.

Cos'è XAMPP

Una distribuzione Apache gratuita che installa un server web completo sul tuo computer: Apache, il database MariaDB, PHP e Perl, pronti per sviluppare e collaudare in locale senza toccare un server di produzione.
