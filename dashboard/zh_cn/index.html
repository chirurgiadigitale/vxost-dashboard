技术栈

已安装组件

Apache

监听 80 与 443 端口的 HTTP 服务器，支持虚拟主机。

MariaDB

监听 3306 端口的关系型数据库，完全兼容 MySQL。

PHP 8.2.4

服务端脚本语言，基于 Zend Engine 4，包含常用扩展。

Perl

可用于 CGI 与自动化任务的脚本语言。

仅供开发使用

VXOST 仅面向开发用途。部分配置便于本地开发，但一旦让他人可以访问此安装，就会存在安全风险。

请运行 sudo /Applications/VXOST/vxostfiles/vxost security 以加固此安装。

社区

VXOST 自 2015 年起投入使用，背后有一个庞大的社区。你可以在源代码所在的 GitHub 上参与：报告问题、提出修改，或者只是读一读它的工作方式。

什么是 VXOST

一个免费的 Apache 发行版，在本机安装完整的 Web 服务器：Apache、MariaDB 数据库、PHP 与 Perl，随时用于本地开发与测试。
