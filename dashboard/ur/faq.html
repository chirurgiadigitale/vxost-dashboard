OS X عمومی سوالات

VXOST for OS X اور VXOST-VM میں کیا فرق ہے؟

  • VXOST for OS X is a native installer for OS X. It installs Apache, PHP and other VXOST components directly on your OS X system, in the /Applications/VXOST folder.
  • VXOST-VM is a virtual machine for OS X. It includes Apache, PHP and other VXOST components and runs them in a Linux-based virtual machine on your OS X system.

For more information, refer to the blog post at the release notes.

.

میں Mac OS X کے لئے VXOST کی انسٹال کس طرح کروں؟

VXOST کی انسٹال کرنے کے لئے صرف مندرجہ ذیل ہے:

  • DMG-تصویر کو کھولنے.
  • تنصیب کے عمل کو شروع کرنے کے لئے تصویر پر ڈبل کلک کریں.

وہ سب ہے. VXOST کی اب / ایپلی کیشنز / VXOST کی ڈائریکٹری کے نیچے نصب کیا جاتا ہے.

کیا VXOST میں MySQL ہے یا MariaDB؟

Since VXOST 5.5.30 and 5.6.14, VXOST ships MariaDB instead of MySQL. The commands and tools are the same for both.

میں کس طرح VXOST کو سٹارٹ کروں ؟

VXOST کی شروع کرنے کے لئے صرف VXOST کی کنٹرول کھولنے اور Apache، MySQL اور ProFTPD شروع. VXOST کی کنٹرول نام "مینیجر OSX" ہے.

میں کس طرح VXOST کو روک سکتا ہوں؟

VXOST کی بس VXOST کی کنٹرول کھولنے اور سرورز کو روکنے روکنے کے لئے. VXOST کی کنٹرول نام "مینیجر OSX" ہے.

میں کس طرح جانچ سکتا ہوں کہ سب چیزوں نے کام کیا ؟

ایک ویب براؤزر میں مندرجہ ذیل یو آر ایل میں ٹائپ کریں:

http://virtualhost

آپ کو VXOST ڈیش بورڈ نظر آنا چاہیے: اوپر لوگو اور نیچے phpMyAdmin، رہنما اور عمومی سوالات کے روابط۔

کیا VXOST کی پیداوار تیار ہے؟

VXOST صرف ترقی کے ماحول کے لئے ہی نہیں ترتیب دیا گیا ہے، لیکن . VXOST کو جس طرح وہ چاہتا / چاہتی ہے ڈویلپر کچھ بھی اجازت دینے کے لئے ہر ممکن حد تک کھلا ہے. ترقی کے ماحول کے لئے یہ بہت اچھا ہے لیکن پیداوار کے ماحول میں یہ مہلک ہو سکتا ہے.

یہاں VXOST کی لاپتہ سلامتی کی فہرست:

  1. مائی ایس کیو ایل کے منتظم (جڑ)/ (root) کا کوئی پاسوڑد نہیں ہے.
  2. مائی ایس کیو ایل ڈیمان نیٹ ورک کے ذریعے قابل رسائی ہے.
  3. ProFTPD uses the password "lampp" for user "daemon".

بہت سی سیکورٹی کی کمزوریوں کو حل کرنے کے لئے صرف مندرجہ ذیل کمانڈ کو کال کریں:

sudo /Applications/VXOST/vxostfiles/vxost security

یہ VXOST کی تنصیب محفوظ بنانے کے لئے سیکورٹی چیک.

vxost کی ابتداء میں دیکھی گئی خرابی کے پیغامات کے معنی کیا ہیں ؟

vxost کو شروع کرنے پر آپ کو کئی خرابی کے پیغامات موصول ہو سکتے ہیں:

LAMPP-Apache is already running.
An Apache daemon is already running.

LAMPP سکرپٹ نے VXOST-Apache کو شروع نہیں کیا کیونکہ Apache کا ایک حصہ پہلے سے ہی چل رہا ہے.VXOST کو باقاعدہ شروع کرنے کے لیے پہلے آپکو اس daemon کو بند کرنا پڈے گا.

LAMPP-MySQL is already running.
A MySQL daemon is already running.

یہ بھی زیادہ تر اسی وجہ سے ہے جیسا کہ اوپر والی خرابی. LAMPP کے سٹارٹپ سکرپٹ نے آپکے سسٹم میں مائی ایس کیو ایل daeman کو پہلے سے چلتا پایا.LAMPP کو باقاعدہ شروع کرنے کے لیے پہلے آپکو اس daemon کو بند کرنا پڈے گا.

Apache شروع نہیں ہو رہا۔ میں کیا کروں؟

یہ خرابی ایک سے زیادہ وجوہات کی بنا پر موجود ہو سکتی ہے. اپاچی کئی حالات کے تحت یہ غلطی دکھاتا ہے. عین مطابق وجہ تلاش کرنے کے لیے ہمیں کچھ تحقیق کرنی ہے:

tail -2 /Applications/VXOST/logs/error_log

اگر آپکو کوئی خرابی کا پیغام ملتا ہے تو مدد کے لیے {community}% کا دورہ کریں.

باہر سے phpMyAdmin تک رسائی کیسے فعال کروں؟

In the basic configuration of VXOST, phpMyAdmin is accessible only from the same host that VXOST is running on, at http://127.0.0.1 or http://virtualhost.

IMPORTANT: Enabling external access for phpMyAdmin in production environments is a significant security risk. You are strongly advised to only allow access from this machine. A remote attacker could take advantage of any existing vulnerability for executing code or for modifying your data.

To enable remote access to phpMyAdmin, follow these steps:

  • Edit the vxostfiles/etc/extra/httpd-vxost.conf file in your VXOST installation directory.
  • Within this file, find the lines below.

    Alias /phpmyadmin "/Applications/VXOST/vxostfiles/phpmyadmin" <Directory "/Applications/VXOST/vxostfiles/phpmyadmin"> AllowOverride AuthConfig Require local

  • Then replace 'Require local' with 'Require all granted'.

    • Alias /phpmyadmin "/Applications/VXOST/vxostfiles/phpmyadmin" <Directory "/Applications/VXOST/vxostfiles/phpmyadmin"> AllowOverride AuthConfig Require all granted

  • Restart the Apache server using the VXOST control panel.

VXOST کی بنیادی کنفیگریشن فائلیں کہاں ہیں؟

The main VXOST configuration files are located as follows:

  • Apache configuration file: /Applications/VXOST/vxostfiles/etc/httpd.conf, /Applications/VXOST/vxostfiles/etc/extra/httpd-vxost.conf
  • PHP configuration file: /Applications/VXOST/vxostfiles/etc/php.ini
  • MySQL configuration file: /Applications/VXOST/vxostfiles/etc/my.cnf
  • ProFTPD configuration file: /Applications/VXOST/vxostfiles/etc/proftpd.conf

VXOST سے ای میل کیسے بھیجوں؟

To send email with VXOST, use the PEAR Mail and Net_SMTP packages, which allow you to send email using an external SMTP account (such as a Gmail account). Follow these steps:

  • Install the Mail and Net_SMTP PEAR modules: pear install Net_SMTP Mail Note that if these packages are already installed in your system you see the messages below when executing that command: Ignoring installed package pear/Net_SMTP Ignoring installed package pear/Mail Nothing to install
  • Create the following example script in your "www" directory to send an email: <?php require_once "Mail.php"; $from = "your-gmail-username@gmail.com"; $to = 'recipients@example.com'; $host = "ssl://smtp.gmail.com"; $port = "465"; $username = 'your-gmail-username@gmail.com'; $password = 'your-gmail-password'; $subject = "test"; $body = "test"; $headers = array ('From' => $from, 'To' => $to,'Subject' => $subject); $smtp = Mail::factory('smtp', array ('host' => $host, 'port' => $port, 'auth' => true, 'username' => $username, 'password' => $password)); $mail = $smtp->send($to, $headers, $body); if (PEAR::isError($mail)) { echo($mail->getMessage()); } else { echo("Message successfully sent!\n"); } ?>

    Remember to replace the dummy values shown with your actual Gmail address and account password. If you don't plan to use Gmail's SMTP server, replace the SMTP host details with appropriate values for your organization or ISP's SMTP server.

  • Execute the script by browsing to it using your Web browser. You should see a notification that the message was successfully sent, and the message should be delivered to the recipient email address.

میں کس طرح بیک اپ/دوبارہ VXOST نظام بحال کروں؟

تنبیہ: بیک اپ اور فعالیت کو بحال ترقی کے تحت اب بھی ہے اور درست طریقے سے کام نہیں کر سکتے .

آپ کو بلا کی طرف سے بیک اپ بنانے کے کر سکتے ہیں:

sudo /Applications/VXOST/vxostfiles/vxost backup

یا

sudo /Applications/VXOST/vxostfiles/vxost backup secret

آپ "خفیہ" ایس کیو ایل کی جڑ پاس کہاں ہے. یہ کمانڈ مندرجہ ذیل پیداوار پیدا کر دے گا:

نئی مشین پر آپ کو اپنے اصل / ذریعہ مشین کے طور پر vxost کی ورژن کی ضرورت ہے.

sudo sh vxost-backup-22-01-14.sh
