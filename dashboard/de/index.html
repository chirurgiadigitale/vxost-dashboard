Nur für die Entwicklung

VXOST ist ausschließlich für Entwicklungszwecke gedacht. Einige Einstellungen erleichtern die lokale Arbeit, sind aber unsicher, sobald die Installation für andere erreichbar ist.

Ein Gateway kommt. VXOST GATEWAY, kurz VXOST WAY, macht diese Projekte von außerhalb dieses Macs erreichbar. Eine bereits abgesicherte Installation ist dafür vorbereitet: die virtuelle Maschine und der Client verbinden sich ohne weitere Arbeit. Es lohnt sich, das von Anfang an richtig einzurichten, statt die offenen Voreinstellungen später zurückzunehmen.

Führen Sie sudo /Applications/VXOST/vxostfiles/vxost security aus, um die Installation abzusichern.

Was VXOST ist

Eine kostenlose Apache-Distribution, die einen vollständigen Webserver auf dem Rechner installiert: Apache, die MariaDB-Datenbank, PHP und Perl, bereit für lokale Entwicklung und Tests.
