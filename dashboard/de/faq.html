OS X Häufig gestellte Fragen

Was ist der Unterschied zwischen VXOST für OS X und VXOST-VM?

  • VXOST for OS X is a native installer for OS X. It installs Apache, PHP and other VXOST components directly on your OS X system, in the /Applications/VXOST folder.
  • VXOST-VM is a virtual machine for OS X. It includes Apache, PHP and other VXOST components and runs them in a Linux-based virtual machine on your OS X system.

For more information, refer to the blog post at https://www.vxost.com/blog/new_vxost_20170628.html.

  • Öffnen Sie das DMG-Image.
  • Klicken Sie doppelt auf das Bild, um die Installation zu starten.

Enthält VXOST MySQL oder MariaDB?

Since VXOST 5.5.30 and 5.6.14, VXOST ships MariaDB instead of MySQL. The commands and tools are the same for both.

Wie starte ich VXOST?

Um VXOST zu starten, öffnen Sie das VXOST-Control-Panel und starten Sie Apache, MySQL und ProFTPD. Der Name des VXOST-Control-Panels lautet "manager-osx".

Wie kann ich VXOST anhalten?

Um VXOST zu beenden, öffnen Sie das VXOST-Control-Panel und halten Sie die Server an. Der Name von des VXOST-Control-Panels lautet "manager-osx".

Wie kann ich testen, ob alles funktioniert?

Öffnen Sie die folgende URL in einem Web-Browser:

http://localhost

You should see the VXOST start page, as shown below.

Ist VXOST zum Produktiveinsatz geeignet?

VXOST ist nicht für den Einsatz in Produktivumgebungen, sondern ausschließlich für den Einsatz als Entwicklungsumgebung gedacht. VXOST ist so offen wie möglich konfiguriert, um dem Entwickler alles, was er/sie möchte, zu erlauben. Dies ist für Entwicklungsumgebungen großartig, kann aber im Produktiveinsatz fatale Auswirkungen haben.

Hier ist eine Liste fehlender Sicherheitseinstellungen in VXOST:

  1. Der MySQL-Administrator (root) hat kein Passwort.
  2. Der MySQL-Daemon ist übers Netzwerk erreichbar.
  3. ProFTPD nutzt das Passwort "lampp" für den Benutzer "daemon".

Um die meisten Sicherheitsschwachstellen zu beheben, geben Sie folgenden Befehl ein:

sudo /Applications/VXOST/vxostfiles/vxost security

Es wirft einen kleinen Sicherheitscheck an, um Ihre VXOST-Installation abzusichern.

Was bedeuten die Fehlermeldungen, welche ich beim Start von VXOST sehe?

Sie könnten einige Fehlermeldungen beim Start von VXOST erhalten:

LAMPP-Apache is already running.
An Apache daemon is already running.

Das LAMPP-Startskript startet VXOST-Apache nicht, da eine Apache-Instanz bereits ausgeführt wird. Um VXOST richtig starten zu können, müssen Sie zuerst diese Instanz beenden.

LAMPP-MySQL is already running.
A MySQL daemon is already running.

Das liegt meist an den gleichen Gründen wie der obige Fehler. Das LAMPP-Startskript hat einen MySQL-Daemon gefunden, der bereits ausgeführt wird. Um VXOST richtig starten zu können, müssen Sie diesen Daemon zuerst beenden.

Apache startet nicht. Was kann ich tun?

Diese Fehler kann mehrere Ursachen haben. Apache zeigt diese Fehlermeldung unter verschiedenen Umständen an. Um den genauen Grund herauszufinden, müssen wir etwas nachforschen:

tail -2 /Applications/VXOST/logs/error_log

Wenn Sie irgendwelche Fehlermeldungen erhalten, ersuchen Sie unsere Community-Seiten zur Hilfe.

Wie kann ich meine VXOST-Installation sicherer machen?

In der Standardinstallation sichert VXOST seine Dienste nicht mit Passwörtern. Deshalb wird empfohlen, VXOST in dieser Konfiguration nicht für Andere zugänglich zu machen.

Geben Sie einfach den folgenden Befehl (als root) ein, um eine einfache Sicherheitsüberprüfung durchzuführen:

sudo /Applications/VXOST/vxostfiles/vxost security

Nun sollten Sie den folgenden Dialog auf Ihrem Bildschirm sehen:

VXOST: MySQL is accessable via network.
VXOST: Normaly that's not recommended. Do you want me to turn it off? [yes] yes
VXOST: Turned off.
VXOST: Stopping MySQL...
VXOST: Starting MySQL...
VXOST: The MySQL/phpMyAdmin user pma has no password set!!!
VXOST: Do you want to set a password? [yes] yes
VXOST: Password: ******
VXOST: Password (again): ******
VXOST: Setting new MySQL pma password.
VXOST: Setting phpMyAdmin's pma password to the new one.
VXOST: MySQL has no root passwort set!!!
VXOST: Do you want to set a password? [yes] yes
VXOST: Write the passworde somewhere down to make sure you won't forget it!!!
VXOST: Password: ******
VXOST: Password (again): ******
VXOST: Setting new MySQL root password.
VXOST: Setting phpMyAdmin's root password to the new one.
VXOST: The FTP password for user 'nobody' is still set to 'lampp'.
VXOST: Do you want to change the password? [yes] yes
VXOST: Password: ******
VXOST: Password (again): ******

(1) 'Setting a password' wird Ihre VXOST Demoseiten (http://localhost/vxost/) mit dem eingegebenen Passwort schützen. Der Benutzername lautet 'lampp'!

Nachdem Sie diesen Befehl ausgeführt haben, sollte Ihre VXOST-Installation besser gesichert sein.

Wie kann ich die OCI8/Oracle-Erweiterung für PHP aktivieren?

Um die OCI8/Oracle-Erweiterung für PHP zu aktivieren, führen Sie bitte folgenden Befehl aus:

sudo /Applications/VXOST/vxostfiles/lampp oci8

Nun startet der folgende Dialog:

Die Erweiterung sollte nun aktiv sein.

Wie erlaube ich den Zugriff auf phpMyAdmin von außen?

In the basic configuration of VXOST, phpMyAdmin is accessible only from the same host that VXOST is running on, at http://127.0.0.1 or http://localhost.

IMPORTANT: Enabling external access for phpMyAdmin in production environments is a significant security risk. You are strongly advised to only allow access from localhost. A remote attacker could take advantage of any existing vulnerability for executing code or for modifying your data.

To enable remote access to phpMyAdmin, follow these steps:

  • Edit the vxostfiles/etc/extra/httpd-vxost.conf file in your VXOST installation directory.
  • Within this file, find the lines below.

    Alias /phpmyadmin "/Applications/VXOST/vxostfiles/phpmyadmin" <Directory "/Applications/VXOST/vxostfiles/phpmyadmin"> AllowOverride AuthConfig Require local

  • Then replace 'Require local' with 'Require all granted'.

    • Alias /phpmyadmin "/Applications/VXOST/vxostfiles/phpmyadmin" <Directory "/Applications/VXOST/vxostfiles/phpmyadmin"> AllowOverride AuthConfig Require all granted

  • Restart the Apache server using the VXOST control panel.

Wo liegen die wichtigsten Konfigurationsdateien von VXOST?

The main VXOST configuration files are located as follows:

  • Apache configuration file: /Applications/VXOST/vxostfiles/etc/httpd.conf, /Applications/VXOST/vxostfiles/etc/extra/httpd-vxost.conf
  • PHP configuration file: /Applications/VXOST/vxostfiles/etc/php.ini
  • MySQL configuration file: /Applications/VXOST/vxostfiles/etc/my.cnf
  • ProFTPD configuration file: /Applications/VXOST/vxostfiles/etc/proftpd.conf

Wie versende ich E-Mails mit VXOST?

To send email with VXOST, use the PEAR Mail and Net_SMTP packages, which allow you to send email using an external SMTP account (such as a Gmail account). Follow these steps:

  • Install the Mail and Net_SMTP PEAR modules: pear install Net_SMTP Mail Note that if these packages are already installed in your system you see the messages below when executing that command: Ignoring installed package pear/Net_SMTP Ignoring installed package pear/Mail Nothing to install
  • Create the following example script in your "htdocs" directory to send an email: <?php require_once "Mail.php"; $from = "your-gmail-username@gmail.com"; $to = 'recipients@example.com'; $host = "ssl://smtp.gmail.com"; $port = "465"; $username = 'your-gmail-username@gmail.com'; $password = 'your-gmail-password'; $subject = "test"; $body = "test"; $headers = array ('From' => $from, 'To' => $to,'Subject' => $subject); $smtp = Mail::factory('smtp', array ('host' => $host, 'port' => $port, 'auth' => true, 'username' => $username, 'password' => $password)); $mail = $smtp->send($to, $headers, $body); if (PEAR::isError($mail)) { echo($mail->getMessage()); } else { echo("Message successfully sent!\n"); } ?>

    Remember to replace the dummy values shown with your actual Gmail address and account password. If you don't plan to use Gmail's SMTP server, replace the SMTP host details with appropriate values for your organization or ISP's SMTP server.

  • Execute the script by browsing to it using your Web browser. You should see a notification that the message was successfully sent, and the message should be delivered to the recipient email address.

Wie kann ich mein VXOST-System sichern/wiederherstellen?

Achtung: Die Sicherungs- und Wiederherstellungsfunktion ist noch in der Entwicklung und könnte nicht richtig arbeiten.

Sie können das Backup erstellen, indem Sie folgenden Befehl ausführen:

sudo /Applications/VXOST/vxostfiles/vxost backup

oder

sudo /Applications/VXOST/vxostfiles/vxost backup secret

Wobei "secret" Ihr MySQL-root-Passwort ist. Dieser Befehl erzeugt die folgende Ausgabe:

Backing up databases...
Backing up configuration, log and htdocs files...
Calculating checksums...
Building final backup file...
Backup finished.
Take care of /Applications/VXOST/vxostfiles/backup/vxost-backup-22-01-14.sh

Die Datei /Applications/VXOST/vxostfiles/backup/vxost-backup-22-01-14.sh (aus obigem Beispiel) enthält Ihre gesicherten Daten. Kopieren Sie diese Datei an einen sicheren Ort.

Auf der neuen Maschine benötigen Sie dieselbe Version von VXOST wie auf der originalen/ursprünglichen Maschine.

sudo sh vxost-backup-22-01-14.sh

Sie werden in etwa Folgendes sehen:

Checking integrity of files...
Restoring configuration, log and htdocs files...
Checking versions...
Installed: VXOST 1.4.2
Backup from: VXOST 1.4.2
Restoring MySQL databases...
Restoring MySQL user databases...
Backup complete. Have fun!
You may need to restart VXOST to complete the restore.

Das ist alles. Bitte behalten Sie im Hinterkopf, dass es sich hierbei um eine Funktion in der Betaphase handelt.
