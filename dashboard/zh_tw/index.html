已安裝的元件

Apache

在 80 與 443 連接埠執行的 HTTP 伺服器，支援虛擬主機。

MariaDB

在 3306 連接埠執行的關聯式資料庫，完全相容 MySQL。

PHP 8.2.4

伺服器端腳本語言，採用 Zend Engine 4 與常用擴充套件。

Perl

可用於 CGI 與自動化工作的腳本語言。

僅供開發使用

VXOST 僅供開發用途。部分設定方便本機開發，但若讓他人可存取此安裝就會不安全。

請執行 sudo /Applications/VXOST/vxostfiles/vxost security 以強化此安裝的安全性。

社群

VXOST 自 2015 年起投入使用，背後有一個龐大的社群。你可以在原始碼所在的 GitHub 上參與：回報問題、提出修改，或者只是讀一讀它的運作方式。

什麼是 VXOST

一套免費的 Apache 發行版，在本機安裝完整的網頁伺服器：Apache、MariaDB 資料庫、PHP 與 Perl，隨時用於本機開發與測試。
