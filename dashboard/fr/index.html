Application de bureau

La stack

Ce qui est installé

Apache

Serveur HTTP sur les ports 80 et 443, avec prise en charge des hôtes virtuels.

MariaDB

Base de données relationnelle sur le port 3306, entièrement compatible MySQL.

PHP 8.2.4

Langage côté serveur avec Zend Engine 4 et les extensions habituelles.

Perl

Langage de script disponible pour le CGI et les tâches d'automatisation.

Développement uniquement

XAMPP est destiné au seul développement. Sa configuration facilite le travail en local mais devient risquée dès que l'installation est accessible à d'autres.

Exécutez sudo /Applications/XAMPP/xamppfiles/xampp security pour sécuriser l'installation.

Qu'est-ce que XAMPP

Une distribution Apache gratuite qui installe un serveur web complet sur votre ordinateur : Apache, la base MariaDB, PHP et Perl, prêts pour développer et tester en local.
