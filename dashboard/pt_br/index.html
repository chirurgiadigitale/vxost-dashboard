A stack

O que está instalado

Apache

Servidor HTTP nas portas 80 e 443, com suporte a hosts virtuais.

MariaDB

Banco de dados relacional na porta 3306, totalmente compatível com MySQL.

PHP 8.2.4

Linguagem do lado do servidor com Zend Engine 4 e as extensões habituais.

Perl

Linguagem de script disponível para CGI e tarefas de automação.

Apenas para desenvolvimento

O XAMPP destina-se apenas ao desenvolvimento. Algumas configurações facilitam o trabalho local, mas são inseguras se a instalação ficar acessível a outras pessoas.

Execute sudo /Applications/XAMPP/xamppfiles/xampp security para reforçar a segurança da instalação.

O que é o XAMPP

Uma distribuição Apache gratuita que instala um servidor web completo no seu computador: Apache, o banco MariaDB, PHP e Perl, prontos para desenvolver e testar localmente.
