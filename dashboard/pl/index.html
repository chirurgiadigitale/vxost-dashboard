Stos technologiczny

Co jest zainstalowane

Apache

Serwer HTTP na portach 80 i 443, z obsługą hostów wirtualnych.

MariaDB

Relacyjna baza danych na porcie 3306, w pełni zgodna z MySQL.

PHP 8.2.4

Język po stronie serwera z Zend Engine 4 i typowymi rozszerzeniami.

Perl

Język skryptowy dostępny dla CGI i zadań automatyzacji.

Tylko do celów rozwojowych

XAMPP jest przeznaczony wyłącznie do prac programistycznych. Część ustawień ułatwia pracę lokalną, ale jest niebezpieczna, gdy instalacja stanie się dostępna dla innych.

Uruchom sudo /Applications/XAMPP/xamppfiles/xampp security aby zabezpieczyć instalację.
