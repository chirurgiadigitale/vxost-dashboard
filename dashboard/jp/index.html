開発用途のみ

XAMPP は開発専用です。ローカル作業をしやすくする設定が含まれていますが、インストールを外部から参照できる状態にすると安全ではありません。

次のコマンドを実行してください： sudo /Applications/XAMPP/xamppfiles/xampp security （インストールを安全にします）

XAMPP とは

コンピューターに完全な Web サーバーを導入する無料の Apache ディストリビューションです。Apache、MariaDB データベース、PHP、Perl がそろい、ローカルでの開発とテストにすぐ使えます。
