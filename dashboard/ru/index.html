Только для разработки

XAMPP предназначен исключительно для разработки. Некоторые настройки упрощают локальную работу, но небезопасны, если установка станет доступна другим.

Выполните sudo /Applications/XAMPP/xamppfiles/xampp security чтобы защитить установку.

Что такое XAMPP

Бесплатный дистрибутив Apache, который устанавливает полноценный веб-сервер на компьютер: Apache, базу данных MariaDB, PHP и Perl — для локальной разработки и тестирования.
