Только для разработки

VXOST предназначен исключительно для разработки. Некоторые настройки упрощают локальную работу, но небезопасны, если установка станет доступна другим.

Выполните sudo /Applications/VXOST/vxostfiles/vxost security чтобы защитить установку.

Сообщество

VXOST используется с 2015 года, и за ним стоит большое сообщество. Присоединиться можно на GitHub, где живёт исходный код: сообщите о проблеме, предложите изменение или просто почитайте, как это устроено.

Что такое VXOST

Бесплатный дистрибутив Apache, который устанавливает полноценный веб-сервер на компьютер: Apache, базу данных MariaDB, PHP и Perl, для локальной разработки и тестирования.
