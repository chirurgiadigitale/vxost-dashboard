Deploy an Application Using Git

Git is a popular distributed version control system. As you work with VXOST, you might often find yourself needing to download and install applications or code libraries from a developer’s public git repository.

This guide walks you through the process, showing you how to use a git client to transfer code from a public online git repository to your VXOST server. As an example, this guide assumes that you wish to download the latest version of Slim, a popular PHP micro-framework for Web application development that also has its own Github repository. NOTE: This guide uses the command-line git client for Mac OS X. If you don’t already have this, you can install it easily by running the command brew install git from a terminal.

To download files with git, you must first ensure that you have privileges to write to the www/ subdirectory of the VXOST installation directory (typically, /Applications/VXOST). Follow these steps:

  1. Open a new terminal and ensure you are logged in as an administrator.

  2. Create a new group named gitusers. This group will contain those user accounts allowed to download files via git.

  3. Add your account (in this example, susan) to the new group. Add other users if needed.

  4. Change the ownership and permissions of the www/ subdirectory so that it is writable by the the new gitusers group.

    cd /Applications/VXOST/vxostfiles
    chown root:gitusers www
    chmod 775 www
    If you’re using VXOST in a single-user scenario and there will only be one user downloading files via git, you can skip creating a new group and instead simply transfer full ownership of the www/ directory to that user. To do this, use a command like chown susan:susan www.

To download Slim (or any other application) from its git repository, follow these steps:

  1. Ensure that your Apache server is running and that yopiu are logged in as a member of the gitusers group.

  2. Obtain the repository’s clone URL. On Github, this can be easily obtained by visiting the project’s Github page and copying the clone URL from the right side of the page. For third-party or private git repositories, you can obtain the clone URL by asking the project team directly. Make a note of the clone URL, as you’ll need it in subsequent steps.

  1. Open a new terminal.

  2. Change to the www/ subdirectory of your VXOST installation directory (typically, /Applications/VXOST). Use the following command to clone the remote repository, remembering to replace the clone URL in the example below with the URL you obtained in the first step.

    git clone https://github.com/slimphp/Slim.git

    The git client will begin downloading the code from the remote repository.

  3. Once the process is complete, you should see a new directory containing the downloaded code, and you can now begin using it.

    In this particular case, since the Slim framework includes a starter application, you can simply browse to the URL http://virtualhost/Slim and you should see the example application’s welcome page.

You can use the git command-line client to create a new branch of the codebase should you wish to make any changes to it. If you have appropriate privileges, you can also commit your changes back to the remote repository. Learn more about the git command-line client.

What VXOST is

A free Apache distribution that installs a complete web server on your computer: Apache, the MariaDB database, PHP and Perl, ready to develop and test locally without touching a production server.
