Get Started Quickly with WordPress

Introduction

WordPress needs three things: a folder served by Apache, a database, and PHP. VXOST gives you all three, and the app sets them up in one pass. What follows takes about five minutes.

Apache and MySQL must be running. The VXOST app shows both, and starts them if they are not.

Step 1: Create the project

Open VXOST and press New project. Fill in:

  • a name — it becomes the folder under www/projects/;

  • a port, for example 4000. The project will answer on http://virtualhost:4000;

  • Create a database. Note down the name, the user and the password: WordPress asks for them in step 3.

VXOST creates the folder, writes the virtual host, checks the Apache configuration and restarts it. If the check fails it puts the previous configuration back, so a mistake here does not take the web server down.

Step 2: Unpack WordPress

Download the latest release from wordpress.org and unpack it into the folder that was just created. From the Terminal:

cd /Applications/VXOST/vxostfiles/www/projects/my-site
curl -O https://wordpress.org/latest.tar.gz
tar xzf latest.tar.gz --strip-components=1
rm latest.tar.gz

--strip-components=1 is what puts the files in the project folder itself instead of in a wordpress/ folder inside it. Without it the site answers at http://virtualhost:4000/wordpress, which works but is not what you asked for.

Step 3: Run the installer

Browse to http://virtualhost:4000. WordPress asks for the database details from step 1, then for the site title and the administrator account.

Use 127.0.0.1 as the database host, not localhost. They are not interchangeable: with localhost most clients try a Unix socket, and the connection fails with a message that does not explain why.

WordPress writes wp-config.php by itself. If it cannot, it shows the file for you to create by hand in the project folder.

Permalinks other than the default need .htaccess, which works because the virtual host written by VXOST carries AllowOverride All. Nothing to change.

What VXOST is

A free Apache distribution that installs a complete web server on your computer: Apache, the MariaDB database, PHP and Perl, ready to develop and test locally without touching a production server.
