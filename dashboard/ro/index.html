Ce este instalat

Apache

Server HTTP pe porturile 80 și 443, cu suport pentru gazde virtuale.

MariaDB

Bază de date relațională pe portul 3306, complet compatibilă MySQL.

PHP 8.2.4

Limbaj de scripting pe server, cu Zend Engine 4 și extensiile obișnuite.

Perl

Limbaj de scripting disponibil pentru CGI și sarcini de automatizare.

Doar pentru dezvoltare

VXOST este destinat exclusiv dezvoltării. Anumite setări ușurează lucrul local, dar sunt nesigure dacă instalarea devine accesibilă altora.

Rulează sudo /Applications/VXOST/vxostfiles/vxost security pentru a securiza instalarea.

Comunitate

VXOST este folosit din 2015 și are în spate o comunitate mare. Poți participa pe GitHub, unde se află codul sursă: raportează o problemă, propune o modificare sau pur și simplu citește cum funcționează.

Ce este VXOST

O distribuție Apache gratuită care instalează un server web complet pe calculator: Apache, baza de date MariaDB, PHP și Perl, gata pentru dezvoltare și testare locală.
