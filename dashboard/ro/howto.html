Ce este XAMPP

O distribuție Apache gratuită care instalează un server web complet pe calculator: Apache, baza de date MariaDB, PHP și Perl, gata pentru dezvoltare și testare locală.

XAMPP 8.2.4 · v9.26.0 restilizare

Credite

Această versiune de XAMPP a fost redezvoltată și reelaborată, stilistic și structural, de echipa Chirurgia Digitale în iulie 2026. În speranța unei contribuții semnificative la acest frumos proiect open source.
