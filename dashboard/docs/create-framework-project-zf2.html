Start a New Zend Framework 2 Project

VXOST makes it easy to start developing with PHP, and Zend Framework 2 is one of the most popular PHP development frameworks. This guide walks you through the process of initializing a new Zend Framework 2 project with VXOST.

This guide uses the command-line git client for Mac OS X. If you don’t already have this, you can install it easily by running the command brew install git from your terminal. It also assumes that the new Zend Framework 2 application will be accessible at the URL http://localhost/myapp/.

Follow these steps:

  1. Open a new terminal and ensure you are logged in as administrator.

  2. Within your VXOST installation directory (usually /Applications/VXOST/vxostfiles/), create a new directory named apps/ (if it doesn’t already exist). Then, within this new apps/ directory, create a directory to hold your Zend Framework application and its related VXOST configuration files. In this case, call the directory myapp/.

    cd /Applications/VXOST/vxostfiles/
mkdir apps
mkdir apps/myapp

  3. Clone the Zend Framework 2 sample application repository to the myapp/ directory using git.

    cd /Applications/VXOST/vxostfiles/apps/myapp
git clone git://github.com/zendframework/ZendSkeletonApplication.git

    This will produce a ZendSkeletonApplication/ subdirectory in the myapp/ directory. Rename this newly-created subdirectory to htdocs.

    cd /Applications/VXOST/vxostfiles/apps/myapp/
mv ZendSkeletonApplication htdocs
    This will be the main working directory for your Zend Framework 2 project.

  4. Change to the myapp/htdocs/ directory and run the following commands to update Composer (the PHP dependency manager) and install the Zend Framework 2 components.

    cd /Applications/VXOST/vxostfiles/apps/myapp/htdocs
/Applications/VXOST/bin/php composer.phar self-update
/Applications/VXOST/bin/php composer.phar install

    In case you encounter SSL errors when running the above commands, update the /Applications/VXOST/etc/php.ini file and add the openssl.cafile variable to let PHP know where to find your system’s SSL certificates, then try again.

    openssl.cafile=/Applications/VXOST/vxostfiles/share/curl/curl-ca-bundle.crt

    Here’s an example of what you might see as Composer downloads and installs dependencies.

  5. Next, within the myapp/ directory, create a new conf/ subdirectory.

    cd /Applications/VXOST/vxostfiles/apps/myapp
mkdir conf

    1. Within the new conf/ subdirectory, use your text editor to create and populate a file named httpd-prefix.conf with the following content:

      Alias /myapp/ "/Applications/VXOST/vxostfiles/apps/myapp/htdocs/public/"
Alias /myapp "/Applications/VXOST/vxostfiles/apps/myapp/htdocs/public"
Include "/Applications/VXOST/vxostfiles/apps/myapp/conf/httpd-app.conf"

    2. Within the conf/ subdirectory, also create and populate a file named httpd-app.conf with the following content:

      <Directory /Applications/VXOST/vxostfiles/apps/myapp/htdocs/public>
   Options +FollowSymLinks
   AllowOverride All
   Require all granted
</Directory>

  6. Edit the httpd-vxost.conf file in the etc/extra/ subdirectory of your VXOST installation directory and add the following line at the end to include the httpd-prefix.conf created earlier.

    Include "/Applications/VXOST/vxostfiles/apps/myapp/conf/httpd-prefix.conf"
    Remember to update the above file and directory paths so that they’re valid for your system.

What VXOST is

A free Apache distribution that installs a complete web server on your computer: Apache, the MariaDB database, PHP and Perl, ready to develop and test locally without touching a production server.
