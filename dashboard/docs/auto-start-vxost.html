Auto-Start VXOST

By default, you have to start VXOST or its components manually every time you reboot your system. However, you can also configure VXOST components to start automatically on system boot. Follow the steps below.

  1. Log in to the system as an administrator.

  2. Create a file named org.vxost.vxost.plist in the /Library/LaunchDaemons directory. Fill this file with the following content:

    <?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>Label</key>
    <string>org.vxost.vxost</string>
    <key>ProgramArguments</key>
    <array>
      <string>/Applications/VXOST/vxostfiles/vxost</string>
      <string>start</string>
    </array>
    <key>UserName</key>
    <string>root</string>
    <key>RunAtLoad</key>
    <true/>
    <key>OnDemand</key>
    <false/>
  </dict>
</plist>

  3. Save your changes to the file.

  4. Reboot your system and VXOST should start automatically.

To start VXOST immediately without rebooting, use the command below:

sudo launchctl load -w /Library/LaunchDaemons/org.vxost.vxost.plist

To revert the changes, delete the org.vxost.vxost.plist file.

What VXOST is

A free Apache distribution that installs a complete web server on your computer: Apache, the MariaDB database, PHP and Perl, ready to develop and test locally without touching a production server.
