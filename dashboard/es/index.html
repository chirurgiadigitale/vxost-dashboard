El stack

Qué está instalado

Apache

Servidor HTTP en los puertos 80 y 443, con soporte para hosts virtuales.

MariaDB

Base de datos relacional en el puerto 3306, totalmente compatible con MySQL.

PHP 8.2.4

Lenguaje del lado del servidor con Zend Engine 4 y las extensiones habituales.

Perl

Lenguaje de scripting disponible para CGI y tareas de automatización.

Solo para desarrollo

VXOST está pensado únicamente para desarrollo. Su configuración facilita el trabajo local, pero resulta insegura si la instalación queda accesible para otras personas.

Ejecuta sudo /Applications/VXOST/vxostfiles/vxost security para reforzar la seguridad de la instalación.

Comunidad

VXOST se usa desde 2015 y cuenta con una gran comunidad detrás. Puedes participar en GitHub, donde vive el código: informa de un problema, propón un cambio o simplemente lee cómo funciona.

Qué es VXOST

Una distribución de Apache gratuita que instala un servidor web completo en tu ordenador: Apache, la base de datos MariaDB, PHP y Perl, listos para desarrollar y probar en local.
